# GU v4.0.1 — Thu gọn ô lịch thuê

- Calendar desktop: ô ngày vuông tối đa 72px thay vì kéo to theo cột.
- Calendar mobile: ô ngày vuông 80px, màn hẹp 74px; vuốt ngang giữ nguyên.
- Nút ngày giữ nguyên click, trạng thái, tooltip và keyboard focus.
- Không thay đổi ảnh sản phẩm 1:1 hoặc backend.
- 3 bài kiểm thử mới cho kích cỡ nút và thao tác lịch.

Các đề xuất tính năng nhanh sau bản này: lọc trống theo ngày, tìm ngày trống gần nhất, bảng việc nhận/trả hôm nay, liên hệ khách từ đơn và thao tác giặt hàng loạt. Chưa triển khai trong bản sửa CSS này.
